## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Profile Insights

After building a SkillTwin profile, open the Overview tab to upload a PDF, DOCX,
TXT, or Markdown resume and review role-match and profile-alignment insights.
For LinkedIn, save a profile URL and import LinkedIn's profile PDF, account-data
ZIP export, or individual profile CSVs. Supported export sections include About,
experience, education, skills, certifications, projects, highlights, and posts.
You can also paste profile text. LinkedIn does not expose profile content to this
browser app from a URL alone. Imported profile data is analyzed and stored in
this browser; unverified profile claims do not count as independent skill proof.

## Roadmaps

Open the Roadmap tab in the dashboard to explore role-based learning paths,
track completed topics, and review focus areas informed by your SkillTwin profile.
Roadmap progress is saved in the current browser.
